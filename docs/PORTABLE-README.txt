Inkspace 0.1.0 - Windows 便携版
================================

运行方法
--------
1. 解压此压缩包到任意本地目录。
2. 双击 Inkspace-0.1.0-portable.exe。
3. 在应用中点击“打开 Markdown 文件”直接编辑单个文件，或点击“打开文件夹”管理整个 Markdown 文件夹。

不需要安装，不需要账户，也不需要联网。文档直接保存为 UTF-8 .md 文件。便携版不会修改系统默认应用；如需双击 .md 自动打开，请使用安装版。

Windows 安全提示
--------------
此程序未进行代码签名。Windows SmartScreen 首次打开时可能显示“发布者未知”。
确认文件来自 https://github.com/Ayaname-Rei/first_markdown 后，可选择“更多信息”再选择“仍要运行”。

常用功能
--------
- 左侧栏可创建文件夹、页面和页面的子页面。
- 文档会自动保存；按 Ctrl+S 可立即保存，按 Ctrl+Shift+S 可另存为，关闭窗口前会等待保存完成。
- 双击 Markdown 文件后会打开文件所在目录，并可在左侧栏浏览同目录页面。
- 右上角可选择每篇文档的字体、字号和行宽。
- 支持实时公式、代码块、表格、任务清单、链接和 Markdown 导出。
- 右上角下载按钮可导出 Markdown、HTML 或 PDF。
