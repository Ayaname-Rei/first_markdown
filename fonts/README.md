# Noto Serif SC

- File: `NotoSerifSC-VF.ttf`
- Family: Noto Serif SC
- Type: Variable TrueType font (weight axis)
- Source: https://github.com/google/fonts/tree/main/ofl/notoserifsc
- License: SIL Open Font License 1.1

This folder keeps the local font asset used for note-taking. After installing
the font for the current Windows user, restart Obsidian and select `Noto Serif SC`
in its Appearance or font settings.
